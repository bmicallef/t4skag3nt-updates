# T4SKAG3NT 0.1.1 Foundation Preview

This validation update strengthens unattended application maintenance:

- Preserves the previous signed application before installing an update.
- Requires a healthy relaunch receipt from the new build.
- Restores the previous build automatically if the new build cannot start cleanly.
- Allows a Sparkle-requested relaunch while retaining the normal “keep working” behavior for Command-Q.
- Includes the signed update-recovery helper in package verification.

This remains a Foundation Preview for controlled testing on the designated Mac mini.
