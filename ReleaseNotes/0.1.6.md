# T4SKAG3NT 0.1.6 Model Setup Update

This update makes the AI model setup cleaner and more capable:

- Detects compatible local models already downloaded on the Mac.
- Adds a focused local model library with a broader set of verified Hugging Face MLX models, filtered for this Mac's memory.
- Offers small, balanced, and higher-capability model families from Qwen, Llama, Gemma, Phi, and Mistral where the hardware permits.
- Replaces inline cloud credentials with a guided provider registration window.
- Verifies OpenAI and Anthropic API keys directly with the provider before registration.
- Loads the supported models available to the registered account and allows one or more to be selected.
- Stores provider keys securely in Apple Keychain and preserves compatibility with existing settings.
