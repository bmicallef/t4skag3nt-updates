# T4SKAG3NT 0.1.8 Local Model Roles and Progress

This update makes local model downloads and assignments explicit:

- Asks whether each newly downloaded model should become the main coordination model or remain available for specialist sub-agents.
- Shows the designated coordination model and its readiness directly on the AI models setup page.
- Keeps one or more active model downloads visible after the model library closes.
- Labels every active download by its intended coordinator or sub-agent role.
- Supports multiple concurrent model downloads while applying the storage safety limit to their combined size.
- Detects partial model downloads accurately and resumes selected downloads after an app relaunch or update.
- Preserves all selected local models so the coordinator and sub-agents can route work to them after setup.
