# T4SKAG3NT 0.1.4 Setup Experience Update

This release brings the polished first-run experience to the installed app:

- Adds a three-second branded launch screen with a luminous progress bar.
- Enlarges and aligns the application identity in the setup sidebar.
- Introduces the new “Welcome to your local task agent!” opening experience.
- Adds glossy glass surfaces and larger, more readable onboarding content.
- Carries the electric-blue, teal, and magenta visual language through every setup step.
- Adds step-specific coordinator, model, safety, storage, and completion artwork.
- Centers the primary setup action for a calmer, more consistent flow.

The underlying local-first privacy, approval, storage, model, and update safeguards remain unchanged.
