# T4SKAG3NT 0.1.3 Foundation MVP Candidate

This release introduces the complete first-run and configured workspace experience for the Foundation milestone:

- Adds the new electric-blue, teal, and magenta application identity throughout the app.
- Replaces the configuration form with a guided five-step setup and clear progress.
- Adds a coordinator-centered Home workspace with conversation starters and quick actions.
- Surfaces agent input requests, approvals, active background work, and recent files directly on Home.
- Uses hardware-neutral “local AI server” language throughout onboarding.
- Expands privacy filtering and adversarial tests for financial, identity, medical, tax, and credential data.
- Retains the existing encrypted storage, local-first routing, approvals, budgets, restart recovery, and automatic-update safeguards.

This is the Foundation MVP candidate for final clean-environment and accessibility acceptance.
