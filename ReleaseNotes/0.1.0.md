# T4SKAG3NT 0.1.0 Foundation Preview

This preview establishes the native Mac coordination foundation:

- Named coordinator and persistent specialist agents
- Local MLX and optional OpenAI/Anthropic routing
- Streaming conversations, supported attachments, and multiple windows
- Background task queue with priorities, approvals, budgets, and recovery
- Encrypted private state and bounded `~/Documents/T4SKAG3NT` artifacts
- Health, audit, usage, model-integrity, backup, and restore controls
- Signed automatic updates through Sparkle

This is a Foundation acceptance build. Remote Apple-device clients, Apple
personal-service integrations, Projects, durable semantic memory, and recurring
schedules remain later milestones.
